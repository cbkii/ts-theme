# Generated prototype resources

These files are generated from checked-in vector sources. Project-authored controls and the app-drawer
glyph come from `design/icons/`; the Music/Auxio, Bluetooth, Navigation/Organic Maps and Video
hotseat icons come from the separately licensed Snow assets in `third_party/snow/icons/`.

The Snow-derived SVG and corresponding generated PNG assets are GPL-3.0; see
`third_party/snow/SOURCE.md` and `third_party/snow/LICENSE`. Other project-authored visual assets
remain Apache-2.0. No vendor/DoFun image is copied.

Resource names intentionally match those already present in the local FYD compatibility template,
because a resource-only repack cannot add new compiled resource IDs.
